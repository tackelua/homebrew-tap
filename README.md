# Homebrew Tap for tackelua

Official Homebrew Tap for developer tools created and maintained by [tackelua](https://github.com/tackelua).

## Available Formulae

| Formula | Description | Installation |
| :--- | :--- | :--- |
| **`portctl`** | Pure Rust local port manager & automated Cloudflare Tunnel ingress | `brew install tackelua/tap/portctl` |

## Usage

You can install any formula directly:

```bash
brew install tackelua/tap/portctl
```

Or tap the repository first:

```bash
brew tap tackelua/tap
brew install portctl
```

## Updating

```bash
brew update
brew upgrade portctl
```
